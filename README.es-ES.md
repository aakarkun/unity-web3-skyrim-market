

# 🎮 Web3 Skyrim Market 🎮

![alt text](https://i.ibb.co/Fb8nW0j/Screen-Shot-2022-08-14-at-03-20-51.png)

---

En este proyecto, básicamente fusionamos los juegos Web2 y Web3. Utilizamos PlayFab como backend para la moneda dentro del juego y para mostrar artículos en las tiendas. Luego, añadimos el poder de Web3 a través de Moralis para convertir estos artículos Web2 en NFTs reales.

Logramos esto mediante diferentes tiendas en el mercado. En la tienda de Intercambio (Exchange) puedes canjear Crystal (moneda de PlayFab) por Septim (token ERC-20). Después, con ese Septim, podrás comprar Conjuntos NFT (NFT Outfits) en la Tienda de Conjuntos.

Una vez que poseamos los Conjuntos NFT, los mostraremos en el inventario del jugador y podremos cambiar la apariencia del personaje seleccionando cada uno de ellos :)

**Para comenzar**
1. Descarga este repositorio (como zip o mediante git)
2. Descarga [Unity](https://unity3d.com/unity/qa/lts-releases?version=2021.3)
3. Abre la carpeta del repositorio descargado en Unity
4. Asegúrate de tener la billetera MetaMask instalada tanto en tu navegador como en tu dispositivo móvil
5. Importa la Cronos Testnet a tus billeteras (ambas) y envía algunos TCRO utilizando el [Cronos Faucet](https://cronos.org/faucet)
6. Sigue el [tutorial en vídeo](https://youtu.be/nxezdsQT1Mk)

Consulta [docs.moralis.io/unity](https://docs.moralis.io/unity) para obtener más información.

**Configuración**
* `Platform Target` - Standalone MAC/PC & WebGL
* `Unity Version` - [2021.3.6f1 LTS](https://unity3d.com/unity/qa/lts-releases?version=2021.3)
* `Render Pipeline` - [Built-in Render Pipeline](https://docs.unity3d.com/Manual/built-in-render-pipeline.html)

**Escenas**
* `Assets/_Project/Scenes/Game.unity`

**Dependencias**
* [`Moralis Web3 Unity SDK`](https://github.com/MoralisWeb3/web3-unity-sdk)
* [`PlayFab Unity SDK`](https://docs.microsoft.com/en-us/gaming/playfab/sdks/unity3d/)
